# Portafolio personal

Proyecto del Sprint 4 de TripleTen.  
Este sitio es un portafolio personal desarrollado con HTML y CSS, basado en un diseño de Figma y adaptado para escritorio, tablet y móvil.

## Tecnologías utilizadas

- HTML
- CSS
- Flexbox
- CSS Grid
- Media queries
- Git y GitHub
- GitHub Pages
